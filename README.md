# ⚔ זירת האווטאר

משחק קרב אונליין בסגנון באטל רויאל: בוחרים דמות מ"אווטאר: כשף האוויר האחרון", נכנסים לזירה ונלחמים עד שנשאר רק אחד. הסערה מתכווצת, ויש חומות, פריטים ובוטים.

## הפעלה

```powershell
npm install
```

```powershell
npm start
```

אחר כך פותחים בדפדפן: http://localhost:3000

## לשחק עם חברים

- **באותה רשת (Wi-Fi):** השרת מדפיס כתובת כמו `http://192.168.1.20:3000`. החברים פותחים אותה בדפדפן ומצטרפים לאותה זירה. אם זה לא עובד, צריך לאשר את Node בחומת האש של Windows.
- **דרך האינטרנט (ענן, חינם):** המשחק מוכן לאירוח ב-Render (הקובץ `render.yaml` כבר מגדיר הכול):
  1. מעלים את הפרויקט ל-GitHub.
  2. נכנסים ל-https://render.com עם חשבון ה-GitHub, ובוחרים **New → Blueprint**.
  3. בוחרים את המאגר ולוחצים **Deploy**. אחרי כמה דקות מקבלים כתובת כמו `https://avatar-arena.onrender.com` ושולחים אותה לחברים.
  4. בתוכנית החינמית השרת "נרדם" אחרי 15 דקות בלי שחקנים. הכניסה הראשונה אחרי זה לוקחת בערך דקה.
  5. כל `git push` חדש מעדכן את המשחק בענן אוטומטית.
- Netlify לא מתאים לפה: הוא מארח רק אתרים סטטיים, והמשחק צריך שרת שרץ כל הזמן (WebSocket).

## רמות קושי

באזור האימון הבוטים חלשים במיוחד. לפני קרב בוחרים **קל / בינוני / קשה**. בקל הבוטים מפספסים יותר, מגיבים לאט, יורים פחות ועושים פחות נזק לשחקנים אמיתיים.

## איך המשחק עובד

1. **אזור אימון:** כל מי שמתחבר מופיע בזירה מול 4 בוטים, וחוזר לחיים אחרי 3 שניות.
2. לוחצים **"התחל באטל רויאל!"** ובוחרים כמה בוטים יהיו (0 עד 24). אחרי ספירה לאחור כולם נזרקים לזירה.
3. **הסערה** מתכווצת בשלבים, והנזק שלה גדל. העיגול הלבן המקווקו מסמן את האזור הבטוח הבא.
4. מי שנשאר אחרון מנצח. אחר כך מוצגת טבלת תוצאות וחוזרים לאזור האימון.

## תמונות משלכם

הדמויות מצוירות בקוד. כדי להחליף פורטרט במסך הבחירה, שמים תמונה בתיקייה `public/portraits/` עם שם הדמות, למשל `aang.png` או `toph.jpg`. השמות האפשריים: `aang, katara, sokka, toph, zuko, suki, iroh, azula, mai, tylee, ozai, bumi`.

## הוספת דמויות

כל הדמויות מוגדרות בקובץ `shared/characters.js`. יכולת חדשה מורכבת מסוגים שהשרת כבר מכיר: `projectile`, `melee`, `dash`, `aoe`, `shield`, `heal`, `beam`, `buff`, `multi`, `wallring`. המראה של הדמות מוגדר ב-`public/art.js` (באובייקט `LOOKS` ובפונקציות השיער).

## מבנה הקבצים

- `server.js`: השרת, הסימולציה, הבוטים, הסערה וה-WebSocket
- `shared/characters.js`: הנתונים של כל הדמויות והיכולות
- `public/game.js`: הלקוח (תפריט, ציור הזירה, אפקטים, HUD)
- `public/art.js`: ציור הדמויות והאייקונים
- `public/sfx.js`: אפקטי סאונד מסונתזים
